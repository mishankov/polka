# Полка

Приложения и история буфера обмена — на одной полке вашего Mac. Откройте полку через значок в строке меню, наведите указатель на вырез камеры или используйте **⌘ ⇧ Пробел**. Найдите нужное, выполните действие и вернитесь к работе.

**macOS 27+ · Apple silicon · Интерфейс на русском · MIT**

## Что доступно

- **Быстрый запуск программ macOS.** Поиск по названию, имени `.app` и идентификатору. Стрелки выбирают результат, Enter открывает программу.
- **Калькулятор в поиске.** Введите `1250 * 3`, `(450 + 180) / 2` или `15% от 240`. Результат появляется сразу; Enter копирует его и оставляет полку открытой. Поддерживаются `+`, `-`, `*`, `/`, `^`, скобки, десятичные запятая и точка. `%` означает деление на 100: `100 + 10%` даёт `100.1`.
- **Поиск по буферу с главной полки.** Под приложениями появляются до трёх совпадений в тексте истории. Enter копирует или вставляет запись согласно настройкам, Shift+Enter только копирует. «Показать все записи» открывает историю с тем же запросом.
- **История буфера обмена.** Текст и изображения, поиск, закрепление и удаление. Открывается из списка на полке или сочетанием **⌘ ⇧ V**.
- **Настройки в отдельном окне.** Кнопка с шестерёнкой или **⌘ ,** открывает основные настройки, поведение полки, сочетания клавиш и настройки буфера. Окно запоминает последний раздел и остаётся открытым при переключении в другие приложения. Версия и обновления находятся на вкладке «О приложении».
- **Активность камеры и микрофона.** Постоянный индикатор у выреза: красный для камеры, оранжевый для микрофона, оба цвета при совместной работе. Настройка находится на вкладке «Полка и сочетания».
- **Работа в фоне.** Закрытие полки оставляет историю и сочетания доступными. Запуск при входе в macOS работает без открытия полки. Для полного выхода выберите «Выйти из Полки» через значок в строке меню macOS.

Пользовательские приложения и подключение LLM-провайдеров удалены. Полка работает локально и не требует API-ключа.

## Как пользоваться полкой

Команда «Открыть полку» у значка в строке меню, сочетание запуска и наведение открывают поиск приложений. Значок приложения в Dock не показывается. На мониторах без выреза наведите указатель к середине верхнего края. Полка должна быть запущена. При первом открытии полка показывает короткую подсказку.

Выберите результат мышью или клавишами **↑ ↓**, затем нажмите **Enter**. Программы macOS запускаются обычным способом, полка скрывается. Ошибка запуска остаётся на полке с возможностью повторить действие.

**Escape** закрывает поиск; при записи сочетания в настройках отменяет запись. Щелчок вне полки скрывает её. Полка, открытая наведением, также скрывается при уходе указателя. Настройки открываются в отдельном окне и не скрываются при потере фокуса. Кнопка «Открыть полку» в настройках или стрелка назад в истории возвращает к списку приложений.

Кнопка с шестерёнкой открывает настройки, включая сведения о приложении и обновления. Эти команды и выход доступны также через значок в строке меню macOS. Настройки не открывают рабочее пространство. Полка всегда остаётся чёрной, визуально продолжая вырез камеры, независимо от оформления macOS. Отдельное окно настроек всегда использует тёмное оформление; настройки контрастности и уменьшения прозрачности учитываются автоматически.

## Индикатор камеры и микрофона

Индикатор включён по умолчанию и виден всё время обнаруженной активности, даже когда полка закрыта. На экранах без выреза он находится в центре верхнего края. Он не перехватывает щелчки и фокус клавиатуры. Переключатель **«Показывать активность камеры и микрофона»** в настройках применяется сразу и сохраняется после перезапуска. Во время сна и блокировки наблюдение приостанавливается.

Серый пунктир и знак вопроса означают, что активность определить не удалось. Для микрофона проверяются входные потоки Core Audio со связанным аудиоустройством, включая виртуальные аудиовходы; обычное воспроизведение звука не считается использованием микрофона. Состояние mute, передачу записи собеседнику и полноту обнаружения всех камер приложение не гарантирует. Видео и звук не записываются.

Окно индикатора помечено как защищённое от захвата, но некоторые программы демонстрации экрана всё равно могут его показывать. Чтобы гарантированно скрыть индикатор перед демонстрацией, выключите настройку; при этом он исчезнет и с вашего экрана.

## История буфера обмена

Введите текст для поиска, выберите запись стрелками и нажмите **Enter** либо нажмите на запись мышью. Выбор копирует текст или изображение, закрывает полку и вставляет запись в поле, которое было активно до её открытия. Для копирования без вставки используйте **⇧ Enter** или команду «Копировать без вставки» в меню записи.

Для автоматической вставки нужен доступ macOS **«Конфиденциальность и безопасность → Универсальный доступ»**. Кнопка «Разрешить автоматическую вставку…» в настройках открывает системный запрос. Без разрешения или подходящего поля запись только копируется; вставьте её сочетанием **⌘ V**. Разрешение не запрашивается автоматически при первом запуске.

Записи можно закреплять и удалять по одной. В меню истории доступна очистка. На вкладке **«Буфер обмена»** в настройках доступны включение сохранения новых копий, автоматическая вставка, сочетание клавиш и срок хранения незакреплённых записей: 1, 7 или 30 дней.

История хранится локально в зашифрованном файле и восстанавливается после перезапуска. Пределы — 200 записей и 128 МБ. Закреплённые записи имеют приоритет при очистке по лимиту и не удаляются по сроку. Сохраняются обычный текст до 1 МБ и изображения в PNG до 32 МБ. Форматирование текста, файлы из Finder и данные, помеченные исходной программой как конфиденциальные, временные или автоматически созданные, пропускаются. Если программа не помечает конфиденциальный текст, он может попасть в историю.

Наблюдение приостанавливается во время сна и блокировки Mac. Уже лежащее в буфере содержимое при запуске не добавляется. Очистка истории не меняет текущий системный буфер.

## Установка и разработка

Для разработки нужны **Node.js 24.18+**, **npm 11** и **Xcode Command Line Tools** на Mac с Apple silicon и macOS 27 или новее:

```sh
npm ci
npm run native:build
npm run dev
```

Для обычного приложения macOS:

```sh
npm run package
```

Для упаковки нужен полный **Xcode 26+** с выбранной директорией разработчика (`sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`) и установленными компонентами первого запуска (`xcodebuild -runFirstLaunch`). Electron Builder компилирует нативную иконку `build/Everything.icon` в `Assets.car` и совместимый ICNS; PNG с готовой плиткой больше не используется для упаковки.

Сборка создаёт DMG, ZIP и `release/mac-arm64/Polka.app`. Перенесите приложение из DMG в «Программы». Локальная сборка не является проверенным подписанным выпуском; [подробнее о выпуске](docs/macos.md).

```sh
npm run verify
```

Проверка включает типы, сборку, тесты настроек, поиска и системных сервисов, desktop-проверку полки, истории, анимации и индикатора камеры/микрофона. `npm run test:clipboard:paste` отдельно проверяет вставку в другую программу; ей нужен доступ «Универсальный доступ». Для готового `.app` доступны `npm run test:packaged` и `npm run test:packaged:workflows`.

GitHub Actions (`.github/workflows/build.yml`) запускает `npm run verify`, упаковку и проверки готового `.app` для каждого pull request и push в `master`; доступен и ручной запуск. Все шаги выполняются на Apple silicon с macOS 27 и Xcode 27 (`xcode-27`, hosted runner в public preview). DMG и ZIP доступны в артефакте `Polka-macos-arm64` в течение 7 дней, снимки desktop-проверок — в отдельном артефакте. CI-сборки используют ad-hoc подпись.

Workflow `release.yml` собирает и загружает ARM64 DMG, ZIP и `checksums.txt` при публикации GitHub Release. Ручной запуск с `tag` (например, `v0.1.15`) создаёт или повторно использует выпуск и публикует черновик после успешных проверок и загрузки. Тег должен совпадать с версией `package.json` в выбранном коммите. Все jobs используют hosted Apple silicon runner `xcode-27`; сертификаты Apple не нужны, сборки имеют ad-hoc подпись и не проходят notarization.

Для испытаний используйте отдельный профиль: `EVERYTHING_PROFILE=/absolute/test/profile`.
