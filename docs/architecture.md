# Архитектура и решения

## Среда и зависимости

Проверка 2 октября 2026: Apple Security Releases сообщает последнюю стабильную **macOS Golden Gate 27.0.1**, выпущенную 28 сентября. Цель — Apple silicon / arm64; Intel не входит в поддерживаемую macOS 27. Фактическая среда разработки: MacBook Air Mac16,13, Apple M4 (10 ядер), 32 ГБ, **macOS 27.0 build 26A428**, Node 24.18.0. Проверка на 27.0 не подменяет испытания на 27.0.1. Версии npm зафиксированы package-lock.json; зависимости устанавливаются npm ci.

Источники, проверенные при выборе:

- https://support.apple.com/en-us/100100 — актуальная macOS и совместимые устройства.
- https://electron-vite.org/guide/ — electron-vite 5, выбран совместимый Vite 7, поскольку Vite 8 вне peer range.
- https://www.electronjs.org/docs/latest/tutorial/security — sandbox, context isolation, проверка IPC sender и запрет navigation.
- https://nodejs.org/api/sqlite.html — встроенный драйвер SQLite, без нативного ABI-модуля. Синхронный API используется в worker thread.
- https://github.com/justjake/quickjs-emscripten — QuickJS/WASM, ограничение памяти и прерывание исполнения.
- https://codemirror.net/ — CodeMirror 6 для текстового редактора, MIT.
- https://mantine.dev/getting-started/ — Mantine 9, MIT, темы на CSS-переменных.

Electron, React, Mantine, esbuild, fast-xml-parser, iconv-lite и fflate — MIT; QuickJS — MIT, обёртка quickjs-emscripten — MIT; SQLite — public domain; yaml — ISC. Точные лицензии и транзитивный состав смотрите в поставляемых node_modules и `npm ls --all`. Собственный canvas отвечает за растровые жесты и undo: кодирование редактора выполняет браузерный Canvas API. Это ограниченный растровый редактор, не аналог профессионального редактора.

## Границы процессов

`main/index.ts` — доверенная оболочка Electron: окна, меню, выбранные пользователем пути, safeStorage, системные операции. `preload` предоставляет только call/onEvent. UI не импортирует Node и не получает общих файловых API. IPC проверяет зарегистрированный WebContents и главный frame; запросы из iframe отклоняются. Методы state.*, secrets, прямой импорт/экспорт по путям закрыты для renderer.

`main/worker.ts` — отдельный Node worker: SQLite, данные, документы, агент, очередь, сборка esbuild и QuickJS. Архивы обрабатываются в отдельных package workers с progress/cancel; JSON/XML/YAML/Base64/hex — в ограниченных по времени и памяти format workers. Подготовка export snapshot и чтение вложений пока синхронны в core worker и могут задержать другие его запросы. Лимиты 64 МиБ пакета и 128 МиБ распаковки ограничивают нагрузку, но это не полная изоляция производительности. Произвольный код приложения никогда не запускается как Node-модуль.

`core` — транзакционное состояние. Одна SQLite БД с обязательным appId, внешними ключами, WAL и контролем ссылок упрощает атомарное переключение определения и данных, snapshots, независимый экспорт. Безопасность обеспечивается scoped API и проверками ядра, а не секретностью идентификаторов. `runtime` хранит очередь и разговоры, использует тот же action executor, что кнопки. `services/documents` хранит черновики отдельно от версий определений. Внешние пути скрыты из публичной модели документа. Крупные вложения — отдельные управляемые файлы.

## Исполнение расширений

Обработчик компилируется локальным esbuild. Разрешён TypeScript/JavaScript без внешних импортов. QuickJS в WASM имеет память 32 МБ, стек 512 КБ и 3 секунды CPU/wall budget на вызов. Нет Node, Electron, filesystem, network, process или host object references. JSON input/output пересекает границу, затем хост исполняет максимум 32 capability-запроса. Проверки прав выполняются заново при каждой операции. Ограничение — многооперационный обработчик не является одной транзакцией; ранее завершённые эффекты не откатываются автоматически.

UI-компоненты компилируются локально с фиксированными библиотеками из `src/extensions/dependencies.ts`: React, Mantine, hooks, Recharts, Zod и компонентами `@everything/ui`. Браузерная среда заранее собирается в `out/extensions/runtime.js/css`; esbuild при сборке пользовательского кода разрешает только виртуальные ссылки на этот каталог. Нет CDN, установки npm-пакетов или чтения произвольных исходников с диска у получателя. Сам бинарник esbuild находится вне ASAR.

Каждый UI-компонент исполняется в отдельном sandboxed `WebContentsView` с уникальным временным session partition (отдельный renderer process). Node отключён, contextIsolation включён; отдельный preload раскрывает только SDK, уведомления жизненного цикла и тему. Main привязывает sender к конкретным appId/extensionId, проверяет главный frame и лимит запросов. ID из сообщения расширения не служит полномочием. Сеть, загрузки, permissions, навигация, окна и webview блокируются; CSP запрещает прямой доступ к сети, вложенные frame, формы и внешние скрипты. Привилегированные операции доступны только через проверяемый SDK ядра. Внешний ключ подключения загружает trusted host из safeStorage для текущего экземпляра и точного origin; расширение получает результат запроса, не ключ.

Heartbeat preload выполняется в том же renderer event loop. Main уничтожает view, если он не отвечает более 6,5 секунды; элементы остановки/перезапуска находятся в оболочке. Отдельный процесс сохраняет отзывчивость оболочки при синхронном цикле UI; это не фиксированная CPU/RAM-квота Chromium и не независимый security-аудит. Закрытие окна/экрана уничтожает view. Native view скрывается под диалогами, меню и панелью помощника и следует границам видимой области. Темы оболочки и приложения передаются в библиотеку Mantine без переустановки расширения.

Доверенный `AdapterRegistry` расширяется только кодом поставки. HTTPS-адаптеры используют точное разрешение origin, не следуют редиректам, ограничивают время/размер запроса и ответа, поддерживают отмену и отзыв прав. `.everyapp` не регистрирует trusted adapters и не приносит нативные бинарники. Контракт SDK и ограничения описаны в [extensions.md](extensions.md).

Это не защита от неизвестных уязвимостей Chromium/QuickJS или пользователя с локальным доступом к профилю. Поддержание обновлений платформы необходимо.

## Секреты

safeStorage на macOS использует системную связку ключей для ключа шифрования. Файлы секретов содержат только зашифрованные байты, права 0600, атомарная замена. При недоступности шифрования сохранение отклоняется. Ключи не входят в SQLite, экспорт или возвращаемые настройки. Облачный провайдер получает только явный запрос, контекст и результаты инструментов текущего приложения.
