# Данные эмодзи

Полка ищет эмодзи локально. `src/shared/emoji-data.json` содержит 3781 полностью квалифицированную последовательность Unicode Emoji 16.0, категории и русские/английские названия и ключевые слова из CLDR 48. Включены составные эмодзи, флаги, оттенки кожи и смешанные оттенки.

Источники и версии записаны в самом каталоге. Обновление выполняется явно:

```sh
npm run emoji:generate
```

Генератор загружает `emoji-test.txt` с unicode.org и `annotations`/`annotationsDerived` для `ru` и `en` из тега `release-48` репозитория unicode-org/cldr. Он проверяет наличие обоих названий для каждой последовательности. CLDR опускает селектор U+FE0F в ключах; ключи нормализуются только при сопоставлении, оригинальная последовательность для копирования берётся из Unicode.

Unicode и CLDR распространяются по [Unicode License v3](unicode-license.txt). Файл лицензии включён в приложение. Небольшой список разговорных псевдонимов находится в `src/shared/emoji.ts` и распространяется по лицензии проекта.

По умолчанию отображаются стандартные эмодзи без модификаторов кожи. Можно выбрать оттенок или «Все оттенки»; последний вариант также показывает смешанные оттенки. Поиск по вставленному эмодзи находит его точную последовательность независимо от выбранного оттенка. Отображение новых символов зависит от шрифта macOS.
