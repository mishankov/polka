## Измерения и пределы

История буфера: `npm run test:clipboard:images` проверяет изображение 6,5 МБ (старый код молча отбрасывал его), копирование в полном разрешении, сочетание изображения и file URL, сообщение о превышении 32 МБ и продолжение записи после ошибки. `npm run test:clipboard:images -- --native` дополнительно проверен с реальным macOS `screencapture` в PNG и TIFF. Нативные PNG-представления читаются даже когда Electron показывает только file URL и raw pasteboard formats. Общий объём истории увеличен до 128 МБ; лимит изображения применяется к PNG до base64-кодирования.

Один из контрольных прогонов `tests/core-performance.test.ts`: 10 000 записей; запись 1155.2 мс, query 37.3 мс, export 96.9 мс, import preview 75.5 мс, commit 137.4 мс; пакет 1 113 979 байт, peak RSS 371.3 МиБ. Это Node-процесс с test runner, не память Electron или задержки UI; timing не используется как хрупкое assertion.

ZIP: 64 МиБ compressed / 128 МиБ inflated, 1000 entries; файл 32 МиБ. Выбор документов: до 256 файлов / 64 МиБ, без symlink traversal. Растр: 16 мегапикселей / 8192 на сторону. QuickJS handler: 32 МиБ / 3 секунды. Очередь: два jobs одновременно и 100 ожидающих. Подробные ограничения — документы подсистем.

Numeric crop не имеет draggable marquee. Редактирование меняет черновики; запись внешних файлов остаётся явной. Формат изображения не может молча замениться при сохранении под несовместимым расширением. При принудительном уничтожении процесса последняя правка до autosave 450 мс может потеряться; обычный выход ожидает flush.

## Поток ответов без дублирования в 0.1.6

Накопленный текст всего запроса больше не используется как текущий ответ. Отдельный streamingText содержит только текст текущего обращения; при добавлении сообщения в историю он очищается в том же обновлении. Сравнение сообщений по одинаковому тексту удалено: реальные отдельные ответы с совпадающими словами сохраняются.
