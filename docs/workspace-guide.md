# Everything App

Персональные приложения для ваших задач — на вашем Mac. Создайте учёт проектов, каталог вещей или рабочий инструмент: опишите идею AI-помощнику либо соберите приложение вручную. Данные и документы сохраняются локально, а готовым приложением можно поделиться через файл `.everyapp`.

**macOS 27+ · Apple silicon · Интерфейс на русском · MIT**

![Приложение «Проекты мастерской»: семь задач на доске со столбцами «Планы», «В работе» и «Готово»](screenshots/project-board.png)

_Пример приложения с демонстрационными данными. Доска, таблица, календарь и заметки находятся в одном рабочем пространстве._

Проект активно развивается. Сейчас доступна локальная сборка; подписанный выпуск и обновление между реальными выпусками ещё требуют проверки. [Текущее состояние и ограничения](validation.md).

## Что можно делать

- **Организовать свои данные.** Добавляйте поля и записи, ищите и сортируйте их. Показывайте одни и те же данные в таблице, на доске, в календаре или на диаграмме.
- **Создавать и менять приложения с помощником.** Опишите задачу обычными словами, затем попросите добавить экран, поле или действие в уже открытое приложение.
- **Работать с файлами.** Открывайте текстовые документы и изображения, редактируйте черновики и сохраняйте результат.
- **Держать нужное под рукой.** Откройте приложение в отдельном или компактном окне либо как панель поверх других окон.
- **Быстро открывать приложения.** Нажмите **⌘ ⇧ Пробел**, найдите приложение и нажмите **Enter**. Приложения Everything App открываются прямо в панели, установленные программы — в macOS.
- **Автоматизировать повторяющиеся действия.** Настраивайте правила по расписанию и событиям; результаты и ошибки видны во «Входящих и фоновых задачах».
- **Делиться приложениями.** Экспортируйте шаблон без личных данных или выберите записи и вложения для передачи. Импорт создаёт независимую копию.

Таблицы, документы и редактор изображений работают без AI и без подключения к сети. Помощнику нужен настроенный провайдер с моделью, поддерживающей инструменты.

## Установка и запуск

Для запуска из исходников нужны **Node.js 24.18+**, **npm 11** и **Xcode Command Line Tools** на Mac с Apple silicon и macOS 27 или новее. Выполните команды в папке проекта:

```sh
npm ci
npm run native:build
npm run dev
```

Чтобы получить обычное приложение для macOS:

```sh
npm run package
```

Сборка создаёт DMG и ZIP в `release/`, а также `release/mac-arm64/Everything App.app`. Откройте DMG и перенесите приложение в «Программы». Готовому приложению Node.js, npm и Command Line Tools не нужны. Локальная сборка не является проверенным подписанным выпуском; подробности — в [руководстве по macOS и выпуску](macos.md).

## Первое приложение

### С AI-помощником

1. Откройте **«Настройки» → «Подключение AI»** (настройки также открываются сочетанием **⌘ ,** или через меню Everything App). Выберите **OpenAI / совместимый API** или **Anthropic**, укажите адрес API, свой ключ и модель.
2. Нажмите **«Проверить и получить модели»**. Если модель ещё не выбрана, выберите её и повторите проверку. Проверка выполняет небольшой запрос к провайдеру.
3. На главной опишите, что хотите создать, и нажмите стрелку отправки или **Enter**. Для новой строки используйте **Shift+Enter**. Например:

   > Создай приложение для проектов мастерской: задачи, сроки и доску со статусами «Планы», «В работе», «Готово».

4. Откройте созданное приложение через боковую панель. Чтобы изменить его, откройте **«Помощник»** или нажмите **⌘ J** и опишите следующую задачу: «Добавь поле стоимости и диаграмму расходов».

![Главная страница с описанием приложения для проектов мастерской в поле ввода](screenshots/home.png)

_Главная — место, где можно начать с описания своей задачи. На скриншоте запрос ещё не отправлен._

### Без AI

1. На главной нажмите **«+» → «Создать вручную…»**, укажите название и назначение приложения.
2. В открытом приложении выберите **«Приложение» → «Изменить экраны и данные»**. Добавьте структуру данных, поля и нужные экраны.
3. Проверьте изменения и нажмите **«Применить новую версию»**, затем добавьте первую запись.

Если у вас уже есть файл `.everyapp`, выберите **«+» → «Открыть файл приложения…»**. Перед импортом можно проверить состав пакета и требуемые разрешения. Права отправителя не переносятся — доступ для своей копии вы выдаёте отдельно.

## Документы, изображения и форматы

В приложении с текстовым экраном можно открыть несколько файлов, целую папку или перетащить файлы в окно. Переключайтесь между вкладками, редактируйте текст, выбирайте кодировку и окончания строк. Черновики сохраняются локально; запись изменений в исходный файл выполняется через сохранение.

![Текстовый редактор с вкладками «Материалы.txt» и «План мастерской.md» и планом работы на неделю](screenshots/documents.png)

Для JSON, XML, YAML, Base64 и hex есть экран конвертера: ввод с подсветкой кода, проверка и форматирование, кодирование и декодирование, предпросмотр результата и сохранение новым документом. Обработка выполняется локально. Компонент редактора кода также доступен пользовательским экранам.

Для изображений есть кисть, ластик, обрезка, изменение размера, поворот, отражение и отмена изменений. Подробнее о форматах и пределах — в [руководстве по документам и редакторам](document-workflows.md).

## Ваши данные и доступ

Приложения, записи, черновики и история хранятся в локальном профиле. При использовании AI провайдер получает ваш запрос, контекст текущей задачи и данные, которые помощник запрашивает для её выполнения. API-ключ хранится локально в защищённом хранилище и не включается в экспорт приложения.

Доступ к сети, буферу обмена, фоновым функциям и другим возможностям выдаётся каждому приложению отдельно: **«Приложение» → «Свойства и доступ»**. Здесь же на вкладке **«Восстановление»** можно создать точку восстановления. Восстановление заменяет текущие данные выбранным снимком и требует подтверждения.

Для передачи откройте **«Приложение» → «Экспортировать…»**, выберите шаблон или нужные данные и проверьте предпросмотр. Ключи, системные разрешения и внешние пути в пакет не входят.

Закрытие окна оставляет фоновые правила работать. Команда **«Приложение» → «Остановить приложение»** отменяет его задания и выключает наблюдателей. Для полного выхода используйте меню Everything App.

## Полка и быстрый запуск

Наведите указатель на вырез камеры и задержите примерно на треть секунды либо нажмите **⌘ ⇧ Пробел** из любой программы. Откроется одна и та же чёрная полка со списком приложений и фокусом в поиске. Меню предыдущей программы останется в строке меню macOS. На мониторах без выреза наведите указатель к середине верхнего края. Everything App должен быть запущен.

Первой в списке идёт **«История буфера обмена»** — встроенное приложение. Далее доступны ваши приложения Everything App и установленные программы macOS с их иконками. Остановленные приложения тоже доступны; архивные скрыты, избранные личные приложения стоят выше остальных личных приложений. Поиск работает по названию и описанию, а для программ macOS — также по имени `.app` и идентификатору приложения. Выберите приложение стрелками **↑ ↓** и нажмите **Enter** либо нажмите на него мышью.

Приложение Everything App запускается и открывается прямо на полке: здесь можно работать с записями, документами и пользовательскими экранами. Полка увеличивается для работы с приложением, сохраняя положение у верхнего края. Стрелка назад возвращает к списку, кнопка открытия в отдельном окне переносит работу в обычное окно. **Escape** или щелчок вне панели скрывает её. При открытии наведением уход указателя также закрывает полку после небольшой задержки. При уменьшении движения в macOS анимация отключается.

Наведение и сочетание быстрого запуска всегда возвращают к поиску приложений. Черновики документов сохраняются перед сменой приложения, возвратом к списку и выходом из платформы. Сочетание истории буфера сразу открывает встроенное приложение на той же полке.

Программы macOS отмечены подписью **macOS**. Выбор запускает программу обычным способом и скрывает полку. В список входят приложения из `/Applications`, `~/Applications`, системных папок и дополнительные приложения, найденные Spotlight; внутренние помощники внутри `.app` и фоновые служебные bundles не показываются. Список обновляется при открытии полки, а названия и иконки кешируются. Если запуск не удался, панель показывает ошибку и позволяет повторить выбор.

В **«Настройки» → «Ваше рабочее место» → «Полка и быстрый запуск»** можно включить или отключить наведение, назначить своё сочетание или отключить его. Нажмите поле сочетания и затем нужные клавиши с **Command**, **Control** или **Option**; **Escape** отменяет ввод. Если сочетание занято, прежнее остаётся рабочим. Быстрый запуск также доступен в боковой панели, меню Everything App и значке в строке меню — в том числе когда основное окно закрыто.

## История буфера обмена

Откройте **«История буфера обмена»** в списке приложений на полке или нажмите **⌘ ⇧ V** для прямого перехода. История также доступна через меню Everything App и значок в строке меню. Это та же полка, без отдельного окна истории; стрелка назад возвращает к приложениям. **⌫ Backspace** также возвращает к приложениям, если строка поиска пуста; при введённом запросе удаляет текст.

Введите текст для поиска, выберите запись стрелками **↑ ↓** и нажмите **Enter** либо нажмите на запись мышью. Выбор копирует текст или изображение, закрывает полку и вставляет запись в поле, которое было активно до её открытия. Переход из списка приложений в историю сохраняет это поле. Для копирования без вставки нажмите **⇧ Enter** или выберите **«…» → «Копировать без вставки»**. **Escape** закрывает историю, а в просмотре записи или подтверждении очистки сначала возвращает к списку.

Для автоматической вставки нужен доступ macOS **«Конфиденциальность и безопасность → Универсальный доступ»**. Кнопка **«Разрешить…»** в истории или **«Разрешить автоматическую вставку…»** в настройках открывает системный запрос; разрешите указанное там приложение. При разработке это может быть Electron или нативный помощник. После выдачи доступа откройте нужное поле и заново вызовите полку. Без разрешения, при отсутствии подходящего поля или при отключённой автовставке запись только копируется — вставьте её сочетанием **⌘ V**. Переключатель **«Вставлять выбранную запись в предыдущее поле»** находится в настройках истории. Выбранная запись остаётся в системном буфере.

Можно закреплять записи и удалять их по одной. В меню **«…»** самой панели доступна очистка истории. В **«Настройки» → «Ваше рабочее место» → «История буфера обмена»** доступны включение сохранения новых копий, смена сочетания клавиш и срок хранения незакреплённых записей: 1, 7 или 30 дней (по умолчанию — 7).

История сохраняется локально в зашифрованном файле профиля и восстанавливается после перезапуска. Общие пределы — 200 записей и 128 МБ; закреплённые записи имеют приоритет при очистке по лимиту и не удаляются по сроку. Сохраняется обычный текст до 1 МБ и PNG-представление изображений до 32 МБ. Форматирование текста, файлы из Finder и данные, помеченные исходной программой как конфиденциальные, временные или автоматически созданные, пропускаются. Если программа не помечает конфиденциальный текст, он может попасть в историю. Очистка истории не меняет текущий системный буфер обмена.

Наблюдение работает, пока Everything App запущен, включая работу с закрытым главным окном; на время сна и блокировки Mac оно приостанавливается. При запуске уже лежащее в буфере содержимое не добавляется — история начинается со следующего копирования. Для локальной разработки после обновления исходников выполните **`npm run native:build`**. Без нового помощника наблюдение недоступно; панель показывает сообщение об ошибке.

## Для разработчиков

Приложение построено на Electron, React/TypeScript, Mantine и SQLite. Зависимости закреплены в `package-lock.json`.

```sh
npm run verify
```

`verify` выполняет проверку типов, сборку, тесты и сценарии desktop-интерфейса. Для проверки готового `.app` используйте `npm run test:packaged` и `npm run test:packaged:workflows` после упаковки.

Для отдельного тестового профиля задайте `EVERYTHING_PROFILE=/absolute/test/profile`. Не используйте рабочий профиль для испытаний импорта и восстановления. Скриншоты этого README можно переснять командой `npx tsx scripts/readme-screenshots.ts` после `npm run build`: сценарий создаёт демонстрационные данные во временном профиле и удаляет его после завершения.
