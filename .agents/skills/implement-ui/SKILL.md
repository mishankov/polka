# Implement UI

Use [Birman's UI/UX guidance](references/birman-ui-ux.md) when designing or
reviewing product interfaces or changing their navigation, controls, layout,
or interaction states.

## Impeccable

Use Impeccable for a focused pass on a screen, flow, or component. Choose
`critique` for UX feedback, `audit` for implementation quality such as
accessibility and responsive behavior, or `polish` for a requested visual
refinement. For example, in Codex use
`$impeccable critique the settings screen`. Follow the project's design system
and this skill's guidance when applying findings.

## Verify implementation

After implementation, run the updated UI and exercise the changed functionality
using the project's available runtime or test harness. Capture the screens or
states that demonstrate the change. Embed or attach the screenshots in your final
response. If you can't capture the updated UI, report the specific blocker.

## Web UI

Follow the [UI SDK guidance](references/ui-sdk.md) when implementing or changing
web UI components, screens, forms, or interactions, or when the user requests
UI SDK.
